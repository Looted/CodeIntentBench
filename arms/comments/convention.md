Product decisions are recorded as comments in the code, right above the functions they apply to: a block that starts with `// Decision <id>:` and gives what was decided, why, its status (a decision marked "not current" was closed or replaced and no longer holds), its firmness (firm: a person set it; follow it, and ask before changing it. default: a delegated or agent choice; follow it, and supersede it only on evidence that it is wrong. exploratory: a flagged guess; revisit it when you touch the area) and where it applies. Record new decisions the same way, beside the code they govern, and read the ones in the code you change before changing behaviour.
