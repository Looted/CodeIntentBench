# kibi-proved

The `kibi` arm on a knowledge base that a team proving its requirements would have: a proof integration
(`.kb/proof/integrations.json` running `kibi proof run-steps`) and a few requirements, on topics no arc probes,
already at `required_evidence: tested` with proof contracts, step files and receipts made at setup. A new
requirement the agent records then finds the proof setup in place, as it would in such a team, instead of
building it from nothing. The plain `kibi` arm in the same batch is its control.
