# billing-admins-crowded

The side-effect arc `billing-admins` on the crowded store: the same steps, grading and hidden tests (its NOTES.md describes
the decision, the shared code and the hidden test). `kb_variant: crowded` gives every arm the store of
`kb/e7acb46f9bc6-hide-why-crowded`: the 182 decisions of the base and 1165 generated ones on the same topics,
about other products and services (`kb/gold/crowd.py`; none governs apps/papra-server, none is linked to code).

Shortlist item 4 of the Nov 25 review (`fable-nov25-cost-and-harder-bench.md`): the request never names the
decision, so an arm has to find it from the code it touches. This set favours tools that react to the code
being edited and must be reported next to the unlinked-decision set, never alone.
