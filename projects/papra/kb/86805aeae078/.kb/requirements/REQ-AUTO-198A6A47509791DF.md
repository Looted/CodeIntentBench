The ingestion error folder and post-processing move folder accept absolute paths (INGESTION_FOLDER_ERROR_FOLDER_PATH, INGESTION_FOLDER_POST_PROCESSING_MOVE_FOLDER_PATH), and the watcher must not ingest files under such a folder.

## Context

Issue #482 reported that absolute error and move folder paths made the file watcher ignore every file under `/` (maintainer CorentinTh, 2025-09-08). The fix accepts absolute paths and skips only files under those folders. Why the watcher must skip its own error and move folders: reason not stated.

## Source

> You can already set an absolute path for those folder using those env variables
